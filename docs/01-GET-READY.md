# 01 — GET READY

This is **Part A** of the beginner tutorial.

Time: **about 20–30 minutes**

> ⚠️ This will hold real business/client information — use a **PRIVATE repository** (a GitHub project folder that is not public). See **[PRIVACY.md](PRIVACY.md)**.

Before you start, one important note:

> The Claude desktop app's **Code** tab (the part of the app that can open and work with folders on your computer) currently requires a paid Claude plan: **Pro, Max, Team, or Enterprise**. If you do not have one of those plans yet, stop here before spending more setup time.
>
> Official guide: https://code.claude.com/docs/en/desktop-quickstart

You do **not** need a terminal for this beginner path.

---

## 1) Create or sign into your GitHub account

If you already have a GitHub account, sign into it in your browser now.

If you do not have one yet:

1. Go to **https://github.com/signup**
2. Follow GitHub's account-creation steps
3. Finish any email verification GitHub asks for

[SCREENSHOT: GitHub sign-up page]

Official help:

- https://docs.github.com/en/account-and-profile/how-tos/account-management/creating-an-account-on-github

Plain English: GitHub is the online place where your saved versions can live after you push them.

---

## 2) Install GitHub Desktop and sign in

GitHub Desktop helps you save versions of your brain on your computer and later send them to GitHub.

### Install GitHub Desktop

Go to:

- **https://github.com/apps/desktop**

Official install help:

- https://docs.github.com/en/desktop/installing-and-authenticating-to-github-desktop/installing-github-desktop

Verified install notes:

- **Windows:** download for Windows, then double-click the setup file
- **Mac:** download for macOS, then double-click the zip and open the GitHub Desktop app

### Sign in to GitHub Desktop

Use the same GitHub account you want to use for this brain.

- **Windows:** **File → Options → Accounts** → **Sign Into GitHub.com** → **Continue With Browser**
- **Mac:** **GitHub Desktop → Settings → Accounts** → **Sign Into GitHub.com** → **Continue With Browser**

Official sign-in help:

- https://docs.github.com/en/desktop/installing-and-authenticating-to-github-desktop/authenticating-to-github-in-github-desktop

---

## 3) Get the Realtor Brain folder onto your computer

Now you need the starter project folder on your computer.

You can do this in either of these verified ways:

### Option A — From GitHub Desktop

1. In GitHub Desktop, click **File → Clone Repository** (**clone** means make a copy of the project from GitHub onto your computer)
2. Choose the starter project
3. Next to **Local Path**, click **Choose...**
4. Pick where you want this folder to live on your computer
5. Click **Clone**

### Option B — From the GitHub page

1. Open the GitHub page for this starter project
2. Click **Code**
3. Click **Open with GitHub Desktop**
4. Choose where you want the folder to live
5. Click **Clone**

[SCREENSHOT: GitHub Desktop Clone Repository screen]

Official help:

- https://docs.github.com/en/desktop/adding-and-cloning-repositories/cloning-and-forking-repositories-from-github-desktop
- https://docs.github.com/en/desktop/adding-and-cloning-repositories/cloning-a-repository-from-github-to-github-desktop

Plain English: **Local Path** means the place on your computer where this Realtor Brain folder will live.

When this step is done, you should have a real folder on your computer. That is a big milestone. The rest of your tools will all point to this same folder.

---

## 4) Before you add real information, make your own private copy

Before you add any real client or business information, make sure you are working in **your own private repository** (your own GitHub project folder that is not public), not only in the public starter.

The starter template lives here:

- **https://github.com/solidplussol/realtor-ai-brain**

Use one of these paths:

1. **Recommended:** open the starter page above and use **Use this template** to create your own **private repository**
2. **If you already have the starter files on your computer:** create a new **private repository** in GitHub, then put these starter files into that new private GitHub project before adding real information

The key idea is simple: get the starter files first, then make your **own private copy** before you store anything real.

See **[PRIVACY.md](PRIVACY.md)** for the full explanation.

---

## 5) Install Obsidian

Obsidian lets you browse your brain like a library of notes.

Go to:

- **https://obsidian.md/download**

Official help:

- https://obsidian.md/help/Install+Obsidian

Verified install notes:

- **Windows:** under **Windows**, click **Universal**, then run the installer
- **Mac:** under **macOS**, click **Universal**, open the file, then drag Obsidian to **Applications**

---

## 6) Open the Realtor Brain folder as an Obsidian vault

In Obsidian, a **vault** just means a folder opened in Obsidian.

Verified steps:

1. Open Obsidian
2. Next to **Open folder as vault**, click **Open**
3. Select your Realtor Brain folder
4. Click **Open**

[SCREENSHOT: Obsidian Open folder as vault]

Official help:

- https://obsidian.md/help/Vaults/Open+another+vault

If you open the wrong folder, you can close it and repeat these steps.

---

## 7) Install and sign into the Claude desktop app

Claude is the tool that helps build and use your brain.

Use Anthropic's official desktop app instructions here:

- https://code.claude.com/docs/en/desktop-quickstart
- https://code.claude.com/docs/en/overview

Sign in with the Claude account that has your paid plan.

Important reminder:

> The **Code** tab used in this tutorial requires **Pro, Max, Team, or Enterprise**. If Claude asks you to upgrade when you try to use **Code**, your current plan does not include this workflow yet.

---

## 8) Confirm you are using the right Claude plan

Before moving on, make sure this is true:

- you are signed into the Claude desktop app
- your account includes **Pro**, **Max**, **Team**, or **Enterprise**
- you can use the **Code** tab

Official help:

- https://code.claude.com/docs/en/desktop-quickstart

If not, stop here and fix that first.

---

## 9) In Claude, go to Code → Local → Select folder

Use the **Code** tab for this project, not the **Chat** tab.

Verified path:

1. Open the Claude desktop app
2. Click **Code**
3. Select **Local**
4. Click **Select folder**

[SCREENSHOT: Claude Code tab with Local + Select folder]

Official help:

- https://code.claude.com/docs/en/desktop-quickstart

---

## 10) Select the Realtor Brain folder

When Claude asks which folder to open:

1. Choose the same Realtor Brain folder you cloned earlier
2. Confirm the selection

Now all three tools should be looking at the same folder:

- **GitHub Desktop** — for saving versions
- **Obsidian** — for browsing notes
- **Claude** — for building and using the brain

- Do not put passwords, API keys, Social Security numbers, financial-account credentials, or other secrets into the brain.
- Brokerage or company policies may apply before you store client information.
- AI can help organize and analyze information, but you remain responsible for reviewing important business decisions.

Full details: [PRIVACY.md](PRIVACY.md)
