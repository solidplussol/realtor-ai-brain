# START HERE

Welcome. This tutorial is split into two parts so setup and actual use do not get mixed together.

## PART A — GET READY

Time: **about 20–30 minutes**

In Part A, you will:

- create or confirm your GitHub account
- install GitHub Desktop
- get the Realtor Brain folder onto your computer
- install Obsidian
- open the folder as an Obsidian vault (**vault** just means a folder opened in Obsidian)
- install and sign into the Claude desktop app
- confirm you have the required paid Claude plan
- open the same folder in Claude Code

## PART B — BUILD AND USE YOUR BRAIN

Time: **about 45–60 minutes**

These are estimates — if this is your first time using any of these tools, budget extra time.

In Part B, you will:

- tell Claude to **SET ME UP**
- answer a guided interview about your business
- review the brain Claude recommends for you
- approve it in plain English
- add your first real piece of knowledge
- ask your brain your first useful question
- save your progress

## What you will have at the end

By the end, you should have:

- one Realtor Brain folder on your computer
- that same folder open in GitHub Desktop, Obsidian, and Claude
- a brain structure that matches how you work
- at least one real note added to your brain
- a saved version of your progress on your computer and on GitHub after you push
